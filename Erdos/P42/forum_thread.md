## Problem statement (page header)

> **OPEN.** Let `M ≥ 1` and `N` be sufficiently large in terms of `M`. Is it true that for every Sidon set `A ⊂ {1, …, N}` there is another Sidon set `B ⊂ {1, …, N}` of size `M` such that `(A − A) ∩ (B − B) = {0}`?
>
> #42: [Er95]
>
> **Partial Solution.** Sedov in the comments (using ChatGPT and Codex) has proved this is true for `M = 3`. The case `M = 1` is trivial; the case `M = 2` is a little less trivial, but is also proved by Sedov in the comments.

### TerenceTao — 18:51 on 05 Dec 2025

Three trivial remarks:

1. A positive solution to this problem would imply a negative solution to (the first part of) #43, by choosing `A` so that `|A| = f(N)` (i.e., a maximal Sidon set).
2. Without loss of generality one can take `A` to be a maximal Sidon set (this was the original form of the problem).
3. One can remove the requirement that `B` be a Sidon set, because any sufficiently large set will also contain a large Sidon set by a greedy algorithm (of cardinality about square root of that of the original set).

### Thomas Bloom — 19:22 on 29 Apr 2026 — **the key Fourier lemma**

> The 'key lemma' (at least, a special case which suffices for this application) is the following: let `F ⊆ 𝔽_p` be a symmetric set such that `|F| ≤ p/2` and `\hat{1_F}(γ) ≥ −o(p)` for all characters `γ`. If we choose a random subset `B` of size `M` by sampling uniformly from `(0, p/4)` then `F ∩ (B − B) = {0}` with probability `≫_M 1`.
>
> With this lemma the proof is immediate: pick a prime slightly larger than `2N` so that `A` corresponds to a Sidon set in `𝔽_p`, then the Sidon property ensures that `\hat{1_{A−A}}(γ) ≥ −c√p` for some constant `c`, and hence a random `B` as above has `(A − A) ∩ (B − B) = {0}` with probability `≫_M 1`. The probability that `B` is not Sidon is `≪ M⁴ / p`, so as long as `p ≍ N` is large enough depending on `M`, with positive probability a random `B` of size `M` from `(0, p/4)` is both Sidon and satisfies the required property.
>
> Now this key lemma looks interesting … the various proofs in the chat seem like overkill; this should basically be a fairly short Fourier calculation. Similar to lemmas in some papers of Ruzsa.
>
> EDIT 2: I haven't looked carefully at the proof given in the original writeup, which may be valid, but this seems quite delicate, so needs a careful examination (and preferably formalisation as well of course).

### WillSawin — 19:57 on 29 Apr 2026 — **Green-Tao complexity-1 framing**

> If we assume a bound on the Fourier coefficients of nontrivial characters from above and not just from below, the key lemma becomes a special case of a result of Green-Tao. Indeed, the set of linear forms `x_i − x_j` for `1 ≤ i < j ≤ M` in the variables `x_1, …, x_M` has complexity at most `1` in the sense of Green-Tao (Cauchy-Schwarz complexity at most 1) … So by the generalized von Neumann theorem of Green and Tao, a set contains approximately the expected number of tuples of the form `x_i − x_j` for all `1 ≤ i < j ≤ M` as long as its Gowers `U_2`-norm is controlled. Apply this to the complement of `F`, whose `U_2` norm is controlled by the strengthened assumption on the Fourier coefficients of `F`.
>
> From this perspective, the biggest subtlety is that to lower bound the probability that `F ∩ (B − B) = {0}` it suffices to lower bound the Fourier coefficients of `F` and the upper bound is not needed.

### TerenceTao — 21:24 on 29 Apr 2026 — **U² regularity / counting argument expanded**

The proof of the key lemma is phrased in a continuous limit in order to get rid of some epsilons (in particular, to make `f` actually positive (semi-)definite rather than approximately positive definite), but if one prefers the finitary language, one can phrase the argument there as well.

… Apply the arithmetic regularity lemma to model `1_F` (in a `U²` type sense) by some model function `0 ≤ f ≤ 1`. The set `{f ≥ 1 − ε}` is basically the `(1 − ε)`-Fourier spectrum of (the large Fourier coefficients of) `\hat{1_F}`, due to the near-non-negativity of this function. Taking a few sumsets of this set still lands one in a 98%-type spectrum, so by Cauchy–Davenport the measure of this set has to be pretty small. (Here it becomes key that one is working in a group of prime order, or more specifically a group without bounded index subgroups; the key lemma looks like it should fail when bounded index subgroups are present.) So, with high probability, `f(x)` is noticeably less than `1`; in particular, for `M` randomly chosen elements `x_1, …, x_M`, `f(x_i − x_j)` is going to be somewhat less than `1` for all `1 ≤ i < j ≤ M` simultaneously. Because `f` is a good Fourier model for `1_F`, a standard "counting lemma" then allows one to show that the `x_i − x_j` all avoid `F` with positive probability.

The lemma reminds me somewhat of the Green-Sanders quantitative version of Cohen's idempotent theorem; it may also be worth exploring such connections further.

### TerenceTao — 21:51 on 29 Apr 2026 — **the continuous version (★ key clean form)**

> The purely continuous version of the key lemma is actually quite clean, to wit:
>
> **Theorem (Continuous analogue of key lemma).** Let `G` be a connected compact abelian group, and let `f : G → [0,1]` be a measurable function which is positive definite (Fourier transform is non-negative) but not identically `1`. Then for almost every `x_1, …, x_M ∈ G`, one has `f(x_i − x_j) < 1` for all `1 ≤ i < j ≤ M`.
>
> *Proof.* Writing `f` as a Fourier series `f(x) = ∑_ξ \hat{f}(ξ) e(ξ · x)`, the non-negativity of `\hat{f}` makes `f(x) = 1` precisely when `ξ · x = 0 mod 1` for all `ξ` with `\hat{f}(ξ) ≠ 0`. So `{x : f(x) = 1}` is a closed subgroup of `G`, proper because `f ≢ 1`. It cannot be open since `G` is connected, hence has measure zero. Thus `f(x − y) < 1` for almost all `x, y`, giving the claim. ∎
